# Loading Screen Gold: A Tip in 200 Characters

One original loading-screen tip for stressed developers and AI coding agents, written by a small deterministic Node program that writes the tip to `/output/entry.txt`.

Entry: "Your agent finished in 4 seconds. You will spend 4 hours finding out what it finished."

The tip works because it speaks to both sides of the screen at once: the developer waiting on the build, and the agent that already moved on.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No dependencies — Node builtins only. Output is a single line with no trailing newline.
